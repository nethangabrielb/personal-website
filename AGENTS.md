## Project Overview

**Purpose:** Personal engineering portfolio (`nethangabrielb.dev`) presenting Nethan Bagasbas's active role (**Junior Web Developer at Inventra Inc.**), flagship systems (**DevLog**, **Calibrate AI**, **Chirper**), experience and education ledger, and technical background.

**High-level architecture:**
- Static multi-page **Astro** site (`output: "static"`) with **MDX**, Astro Content Layer API (`src/content.config.ts` using `astro/zod`), and **Tailwind CSS v4** via `@tailwindcss/vite` (do not use `@astrojs/tailwind`).
- Routes: `/` (`src/pages/index.astro`), `/about` (`src/pages/about.astro`), `/work/[slug]` (`src/pages/work/[slug].astro`), and `/404` (`src/pages/404.astro`).
- Shared chrome in `src/layouts/BaseLayout.astro` with Astro `<ClientRouter />` (`160ms` cross-fade) and a tiny inline listener for click-to-copy email (`astro:page-load`).
- **Light-Only Stark Monochrome Precision** aesthetic (`#FFFFFF` canvas, `#F6F6F6` surface, `#09090B` ink, zero dark mode, zero chrome accent color). Fonts: `@fontsource-variable/geist` and `@fontsource/ibm-plex-mono`. Read `DESIGN.md` (especially Section 7 hard bans) before changing UI.
- React 19 islands are hydrated only where interactive state is needed:
  - `src/components/WorkShowcase.tsx` (`client:load` on `/` for the desktop split selector and live screenshot stage).
  - `src/components/ArchitectureDiagram.tsx` (`client:visible` on `/work/[slug]` for the interactive orthographic SVG architecture diagram).
- Structured site data lives in `src/data/site.ts`; case study content and architecture graph definitions live in `src/content/work/*.mdx`. Do not falsify or invent career facts, dates, metrics, or internal employer project names.
- Static verification/distribution assets in `public/` (`bagasbas-resume.pdf`, `googleee6af79c75bd2814.html`, `personal-website.png`, favicons, and `robots.txt` / `sitemap.xml` generated by `scripts/generate-seo-files.mjs`) must remain intact in `dist/`.

## Coding, Static Build & Accessibility Standards

- **TypeScript:** Strict Astro config (`tsconfig.json`). Use `@/` alias for `src/` imports and `import type` for type-only imports.
- **Import sorting:** `eslint-plugin-simple-import-sort` enforces sorted imports and exports as hard errors across `.ts`, `.tsx`, and `.astro` (`eslint.config.mjs`).
- **SSR/Static Build Safety:** Astro renders pages and island HTML in Node at build time. Guard browser globals (`navigator`, `window`, `document`) inside client scripts or event handlers.
- **Accessibility & Security:** Maintain keyboard navigation (`Tab`, Arrow keys, `Home`, `End`, `Enter`/`Space`) on interactive islands, visible `:focus-visible` indicators, `prefers-reduced-motion` guards, a mounted `role="status"` live region for clipboard announcements, and `target="_blank" rel="noopener noreferrer"` on external links. Never read or commit `.env` secrets.
